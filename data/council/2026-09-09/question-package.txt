# 背景

一个人（有全职工作，业余时间做开源与投研写作）手上有四个已经存在、各自独立的项目：

**1. prophetmap** — 美股「AI 物理供应链传导图」。27 个层级、89 只标的；每只标的有 5 个人工评定的维度（物理约束强度、AI 收入贡献、护城河捕获、实现时间、护城河锁类型），外加自动拉取的估值分。有每日/每周/每月三个审计脚本（只出报告，永不写数据）。2026-08-17 起有一个冻结的 A/B 实验：87 只名册 + 7 条预注册规则，窗口到 2027-08-17，期间不允许修改评分字段。治理文档里已记录 19 个「已知缺陷」，每条带来源、证伪条件，以及大多标着「本次刻意不修」。Next.js 应用，私有仓库。

**2. assay** — LLM-as-judge 的可信度测试台。核心发现：多个 judge 之间的分歧，主因是评分标准（rubric）未定义，而不是模型个性——补一句外推规则后，judge 间一致率从 53% 升到 83%。

**3. decision-confidence** — 评估第三方风控 API 的可信度（链上代币风险评分）。核心发现：两个来源对同一个代币给出 5 分和 100 分，而且两边都是对的——它们在测不同的构念（一个测权限控制，一个测可交易性）。

**4. agent-tool-interop** — coding agent 的 tool-use 互操作性研究。含一份 15 条的「测量纪律」文档，每条挂一次真实事故。公开仓库。
